915 MHz filter
Design, build and measurement package

UNBUILT PROTOTYPE. All performance below is simulated, not measured.

A passive three-resonator LC network on a 40 x 24 mm, two-layer, 0.8 mm PCB. The package includes editable KiCad files, manufacturing exports, a parts list, Python analysis, a through reference board and a NanoVNA test procedure.

Predicted performance

The estimated board model passes the proposed targets. Package and PCB parasitics are only approximations; fabrication, assembly, tuning and physical validation remain.

Component and ground-return sensitivity

275 of 300 illustrative samples satisfy all modeled targets. This is not measured yield. Independent component tolerances and a limited ground-return range omit coupling, connector uncertainty and other real effects. See design assumptions.

Build and validate

  1. Read ordering and assembly instructions and use the BOM. Keep the specified 0.8 mm stackup.
  2. Order the filter and through-board Gerber ZIPs in fabrication/.
  3. Assemble, photograph and complete the DC continuity checks.
  4. Follow the NanoVNA procedure, recording instrument range and calibration reference planes.
  5. Analyze raw Touchstone exports, compare with simulation and document tuning.

No physical measurements are included. Unsupported frequency coverage stays unverified. The exact NanoVNA model is not known, so no firmware-specific USB control or 1830 MHz capability is assumed.

Verification and next evidence

Read the verification record for actual software and CAD checks. ERC/DRC establish connectivity and layout-rule compliance; they do not establish RF performance. The ideal SPICE netlist is an optional cross-check and has not been run in an external SPICE executable.
